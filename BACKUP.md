# Mop Combat backup

Unity Editor: 2022.3.62f3

This is a source/project backup, not a self-contained project archive.
Assets/02.Assets is intentionally excluded. The local folder is not deleted.

Before opening a fresh clone, restore these third-party assets into their original paths:
- Bananadev's Pack
- BOXOPHOBIC
- Cowsins
- Human Animations
- Photon (PUN 2.55)
- PixPlays
- TextMesh Pro resources
- VFX

Use the same asset versions and preserve original .meta GUIDs. Re-downloading a different version may break scene/prefab references. Local modifications inside the excluded folder are not backed up.
Packages/manifest.json and packages-lock.json record Package Manager dependencies.

Install Git LFS and run git lfs pull after cloning to download tracked binary assets.
The build scene is Assets/Scenes/SplashPark_Arena.unity.
Library, Temp, Logs, UserSettings, generated IDE files, and Bulid are excluded.
